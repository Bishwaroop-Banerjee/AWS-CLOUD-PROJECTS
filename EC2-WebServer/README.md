# EC2 Web Server

A hands-on AWS project demonstrating how to host a static website on an Amazon EC2 instance using Apache HTTP Server.

## AWS Services

- Amazon EC2
- Security Groups

## Technologies

- Amazon Linux
- Apache HTTP Server
- HTML
- SSH

## Project Overview

An Amazon EC2 instance was launched with Amazon Linux and configured to run Apache HTTP Server. A static HTML website was created and hosted on the server and made accessible through the instance's public IPv4 address.
